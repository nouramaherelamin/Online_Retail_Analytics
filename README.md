# Online Retail Analytics

## Setup
1. pip install -r requirements.txt
2. Put the dataset here:  data/raw/Online Retail.csv   (UCI "Online Retail" dataset)
3. streamlit run app.py

Optional: data/processed/clean_transactions.csv and data/processed/customer_rfm.csv
(the RFM segments donut and the Customer Analysis page need customer_rfm.csv).
