# Online Retail Analytics — Orange Theme

This version applies the supplied visual asset pack and the approved Orange / Cream / Charcoal design system.

## Palette
- Primary Orange: `#FF9900`
- Orange Secondary: `#FF7A00`
- Charcoal: `#111827`
- Slate: `#374151`
- Cream: `#F7F5EE`
- Light Surface: `#FFFFFF`
- Border: `#E5E7EB`

## Assets
- `assets/hero.png`
- `assets/icons/` — dataset-specific transparent icons

## Run
```bash
pip install -r requirements.txt
python -m streamlit run dashboard/app.py
```

## Dashboard
- Overview
- Sales Analytics
- Product Analysis
- Customer Analysis
- Geographic Analysis
- Returns & Cancellations

All dashboard paths are relative to the project root.
